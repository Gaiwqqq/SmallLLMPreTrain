# 配置：区分模型结构与训练方法

模型配置决定“网络长什么样”：层数、向量宽度、注意力头数、词表和上下文长度。训练参数决定“怎样学习”：学习率、batch、数据、更新次数。改变后者并不增加模型参数量。

当前教学基线使用 `model/ladder/v001/p039m.yaml` 和 `model/p099m.yaml`；正式模型使用 `model/p213m.yaml`，约 213M 参数、16 层、宽度 1024、上下文 2048。213M 是本轮硬件、时间与学习目标下的工程选择，没有证明它是最优规模。

简单实验用命令行显式记录训练参数；需复用的模型结构放 YAML。不要把机器路径写入结构配置。其余 ladder/scaling 配置仍是草案，文件存在不代表实验完成。

先读 [模型阶段](../docs/01_foundations.md)，再看 [正式预训练](../docs/05_pretraining.md)。学习率选择依据在 [213M 对照实验](../experiments/current/p213m_lr/README.md)。
