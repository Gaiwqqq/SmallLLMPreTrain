# 教学对照：理解分片而不盲目替换 DDP

## 问题与原因

DDP 每卡保留完整模型；FSDP2 管理分片状态。我们先理解分片接口会怎样影响更新，再考虑它是否有实际需要。

## 为什么这样设计

用小模型、FP32 SGD，对照完整模型与 FSDP2 更新，排除大规模和混合精度的额外变量。教学模型返回 dataclass，分片钩子需要可遍历 Tensor 输出，因此用 LossModel 适配层返回 loss Tensor。

这是接口与数学一致性对照，没有做大型模型的显存/吞吐排名。当前 213M 本来能放在单卡，不因“框架更复杂”就更换正式训练路线。

## 结果与结论

更新最大差异 1.86e-9，通过。说明当前教学适配可用；不说明 FSDP2 一定更快，不能推广到所有分片策略。

决定：正式训练保持已验证的 DDP；将分片扩展留给后续有需求的实验。证据 `runs/m03_fsdp/summary.json`、入口 `scripts/train/verify_fsdp.py`，详见 [分布式阶段](../../../docs/04_distributed.md)。
