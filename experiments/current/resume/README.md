# 正确性实验：中断后是否接着同一个训练过程

## 问题与原因

只保存权重可以推理，却可能无法复现后续训练。长任务需要验证恢复了 optimizer、数据位置、调度进度和随机过程。

## 为什么这样设计

从同一初始状态做两条路径：连续训练；训练一段、完整保存、恢复后继续。固定完整 schedule 和全局数据顺序，比较最终参数与 RNG。

加入 BF16、dropout=0.1、不均匀尾部。dropout 会用随机数，这样“只恢复权重或只重新设 seed”的实现更难蒙混过关。普通模型 dropout=0，不代表恢复功能可以省掉 RNG。

## 结果、边界与决定

四卡恢复后 RNG 一致，参数最大差异 2.91e-11，测试通过。因此当前正式路线可以在匹配配置、数据指纹及 world size 时恢复。

不保证改 world size、改数据或改 LR 后还是相同实验。完整恢复点与只保存最终权重需要不同用途和加载方式。
