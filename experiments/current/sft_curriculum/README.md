# 第二轮受控实验：格式与多轮状态

## 为什么做这个实验？

首轮指令类通过率 25%，上下文类 0%。这提示模型对任务边界、用户身份和状态变化掌握不足，但仅凭评分无法确定是数据覆盖、学习率还是基础能力限制。先用答案可核验的小课程验证它是否能学到这些行为，避免直接重复全量 SFT。

## 数据怎样设计？

固定种子 20261006，生成 32,000 个课程会话：25% 大写且无额外文字，25% 精确 JSON，25% 记住数量并做减法更新，25% 更新数量后再回忆用户姓名。训练示范由规则生成正确答案，不调用现有模型写答案。

另从原 SFT **训练划分**随机取 16,000 个会话回放，约占总训练会话的三分之一，帮助保留原有回复行为。两个学习率使用同一份混合、洗牌后的数据。原 SFT 验证数据不加入训练。

另生成 400 个开发会话、400 个诊断测试会话。两者与训练使用不同的提示模板、名称集合及数值区间。JSON、减法等任务族仍相同，因此这属于模板迁移诊断，并不是独立一般聊天验收。诊断测试冻结后不参与当前学习率选择；开发题用于比较。

原始 JSONL、下载格式兼容的清单与 SHA-256 位于 `data/curriculum-v1/`；CPU 预处理产物在 `data/tokenized/curriculum-v1/`。完整会话去重与跨 train/dev 重叠检查必须通过，assistant-only mask 与 2048 截断规则保持不变。显式划分不会再次随机拆分。

## 两个短跑为什么这样设置？

从相同 `exports/chat` 开始全参数 TRL SFT，分别使用 LR=3e-5、1e-4，一轮。前者较保守，后者保留首轮的学习率，能观察适应速度与原有能力损失之间的差异。优化器、调度器从本次新实验重新初始化；不是恢复首轮的优化器状态。

每个任务两卡、每卡 micro-batch=8、梯度累积=4，全局 batch=64。48,000 个有效会话对应约 750 步；实际步数以 Trainer 状态为准，若截断导致无 assistant 标签，会话会被过滤。相比首轮四卡 batch=128，本轮两个组都使用同样的 batch=64，因此两组仍可直接比较。

GPU 0/1 跑 3e-5，GPU 2/3 跑 1e-4，使用独立 rendezvous 端口。现有 vLLM 占用 GPU 0 的约 49 GiB 显存但当时无推理负载；需现场观察剩余显存与训练速度，如出现 OOM，先处理服务占用，保留两组相同配置后重试。

FP32 参数、BF16 计算、assistant-only loss、无 packing、warmup 3%、cosine 调度延续已验证实现。每 250 步保存与验证，完整恢复快照继续由归档器上传 ModelScope。导出的 final 是验证 loss 最优 checkpoint，不一定是最后一步；语义选择必须另看实际回答。

## 用什么判断有效？

先分别生成课程开发题以及原有 40 题一般聊天开发回复，当前 Chat 同样生成一次，作为对照。课程评分只核验最终答案：精确大小写、JSON 对象内容、更新后数量或姓名，并要求完成所有轮次、无结构异常。

判定方向有效需同时满足：两类课程开发通过率均比当前 Chat 高至少 10 个百分点，原有开发题语义审阅未发现明显整体退化。一般开发题不能只看结构 flags；需读取真实回答。若两组均失败，先分析监督位置、错误类型和数据难度，而不是自动再训两轮。

此阈值是当前受控实验的选择条件，不是产品验收条件。之后还要加入更丰富状态更新、开放指令、真正改写与可核验的知识任务，并冻结新的一般聊天测试集。旧 120 题已被看过，只能保留为历史回归。

## 如何运行与审阅？

```bash
cd /diff/gaiwq/llm_pretrain/repo
source scripts/remote/environment.sh
nohup python scripts/remote/curriculum_pilots.py \
  > "$PRETRAIN_ROOT/logs/curriculum-pilots.log" 2>&1 < /dev/null &
```

控制器先生成混合数据、独立 CPU 预处理，再并行启动两个两卡任务。控制器锁防止重复启动；既有实验目录不覆盖。状态为 `runs/sft-curriculum-v1/status.json`，训练日志为 `logs/sft_curriculum_lr*.log`。完成后生成开发回复、课程评分、上传两个候选导出，并进入 `awaiting_general_semantic_review`，不会自动替换聊天服务权重。

源码：[课程生成](../../../scripts/posttrain/build_curriculum.py)、[精确评分](../../../scripts/posttrain/score_curriculum.py)、[远程控制器](../../../scripts/remote/curriculum_pilots.py)。本地 lint 和远程课程/数据回归 7 项检查已通过；实际模型得分必须等训练与生成完成后记录。
